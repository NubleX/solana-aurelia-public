## 02 · Locked design

### Hard facts before the pie chart.

| | |
|---|---|
| **1B** | Hard cap (fixed) |
| **9** | Decimals |
| **80%** | Locked via Streamflow into a Squads vault (24 months) |
| **0** | Mint / freeze after launch |

### What we will not do

Paywall the gallery. Fake volume. Keep freeze or mint power. Ship an on-chain max-wallet that bricks Jupiter routing.

### Why Classic SPL

Token-2022 hooks still shrink DEX and wallet coverage. `$AURA` stays a normal token so Raydium, Jupiter, Orca, and Phantom treat it as one.

Public design commitments - verifiable on-chain.

**Lock model:** 800M leaves the five locked buckets for **one** non-cancelable Streamflow stream into a **Squads v4** vault (payer / team / treasury). Liquidity 200M stays outside. Monthly unlocks land in the vault; distributing a tranche still needs threshold signatures.

## 04 · Steady flow

### A measured release over 24 months

Currency enters circulation progressively. Liquidity grows with it. No large scheduled release is designed as a sudden price shock.

Community ~10.42M / month. Not a 25% TGE unlock.

---

## 05 · Tradeoffs

### What Classic SPL cannot do - and what you keep instead

**Cannot do on-chain**

- No max-wallet hook that rejects oversized balances
- No transfer tax / auto-burn on every swap
- No clawback after freeze is revoked

**Keep instead**

- Full DEX and wallet coverage
- Hard cap that is actually hard (mint gone)
- No developer freeze button - verifiable on-chain
- Soft anti-whale at launch via LP sizing + culture + DAO

Token-2022 is parked, not promised. A later v2 only if DEX support is no longer the bottleneck.
